# VOKKO
### Universal Neural Speech & Music Intelligence Workstation

Автономная утилита для расшифровки видео, аудиозаписей, подкастов, интервью и песен с изоляцией вокала нейросетью **Demucs**, поддержкой семейства моделей **Whisper** и многослойным синтезом **LLM**.

## Что такое VOKKO?

> **VOKKO** превращает неструктурированный звук и шум в **аккуратные документы** с разделением спикеров, расстановкой пунктуации, удалением слов-паразитов и поэтическим делением песен на куплеты и припевы. Вы можете гибко выбирать подходящие модели распознавания речи и языковые модели под ваше оборудование.

## Сравнение возможностей

| Задача / Функция | Базовый Whisper | Облачные ASR-сервисы | **VOKKO Workstation** |
| :--- | :---: | :---: | :---: |
| **Распознавание речи и видео** | Да | Да | **Да (любая модель Whisper на выбор)** |
| **Изоляция вокала в тяжелой музыке** | Нет (много ошибок) | Нет | **Да (Нейросеть Demucs)** |
| **Определение куплетов и припевов** | Нет | Нет | **Да (Интеллектуальный парсер)** |
| **Многослойный синтез рифм (LLM)** | Нет | Нет | **Да (1–5 температурных слоев)** |
| **Определение и разметка спикеров** | Нет | Ограниченно | **Да (Интерактивная диаризация)** |
| **Слияние / Переименование спикеров**| Нет | Нет | **Да (Прямо в интерфейсе)** |
| **Загрузка по ссылкам (YouTube, VK, RuTube, Дзен)** | Нет | Редко | **Да (1500+ платформ через yt-dlp)** |
| **100% локальная приватность** | Да | Нет (данные в облаке) | **Да (Полный офлайн-режим)** |
| **Экспорт в 6 форматов (TXT, DOCX, PDF, SRT, LRC, JSON)** | Только TXT/SRT | 1–2 формата | **Все 6 форматов в 1 клик** |

## Режимы работы

### 1. Режим речи и видео (General Mode)
Предназначен для **интервью, лекций, YouTube-подкастов, стримов, созвонов и голосовых сообщений**:
* **Любые медиаформаты:** загрузка файлов `MP4`, `MKV`, `AVI`, `MOV`, `WEBM`, `MP3`, `WAV`, `FLAC`, `M4A`, `OGG`, `AAC`.
* **Загрузка по URL:** прямая вставка ссылок на **YouTube, RuTube, VK Видео, Дзен, Twitch, TikTok, Telegram** и другие площадки.
* **Распознавание спикеров (Speaker Diarization):** автоматическая кластеризация голосов участников разговора.
* **Интерактивное управление спикерами:**
  * *Переименование:* замена «Спикер 1» на имя человека во всей стенограмме.
  * *Слияние:* объединение реплик нескольких собеседников в одного.
  * *Удаление:* очистка расшифровки от ненужных реплик или шума.
* **Языковая нейрокоррекция речи (LLM):** расстановка смысловой пунктуации, удаление слов-паразитов (*«э-э»*, *«ну»*, *«как бы»*) и исправление оговорок.

---

### 2. Режим музыки и песен (Music Mode)
Специализированный конвейер для **песен, клипов и музыкальных треков**:
* **Изоляция вокала (Demucs):** физическое разделение вокальной партии и аккомпанемента (барабаны, гитары, бас, синты).
* **Автоматическая структура:** определение блоков `[Куплет 1]`, `[Куплет 2]`, повторяющегося `[Припев]`, `[Бридж]` и `[Аутро]`.
* **Многослойный температурный синтез (1–5 слоев):** генерация нескольких вариантов текста при разных температурных режимах с автоматической сборкой единого идеального текста с точными рифмами.

## Экспорт результатов

Экспорт расшифровок в один клик в любой удобный формат:

| Формат | Назначение | Особенности |
| :--- | :--- | :--- |
| **`DOCX`** | Документ Microsoft Word | Фирменная стилизация, заголовки, таблицы диалогов |
| **`PDF`** | Векторный печатный документ | Типографская верстка, кириллические шрифты, шапка проекта |
| **`SRT`** | Субтитры для видео | Миллисекундная точность для Premiere Pro, DaVinci Resolve, Final Cut |
| **`LRC`** | Караоке-текст песни | Построчные таймкоды `[mm:ss.xx]` для медиаплееров |
| **`TXT`** | Чистый текст | Опциональные метки спикеров и посекундные таймкоды |
| **`JSON`** | Структурированные данные | Полное дерево метаданных для разработчиков и интеграций |

## Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/BearCodexx/Vokko.git
cd Vokko
```

### 2. Создание окружения и установка зависимостей
```bash
python -m venv venv

# Активация на Windows:
venv\Scripts\activate

# Активация на Linux/macOS:
source venv/bin/activate

# Установка пакетов:
pip install -r backend/requirements.txt
```

### 3. Запуск
* **На Windows (в один клик):** дважды нажмите на `start.bat`.
* **Через терминал (Windows / Linux / macOS):**
  ```bash
  python run.py
  ```

> [!TIP]
> При первом запуске интерактивный консольный мастер поможет выбрать подходящие модели Whisper и языковой модуль (локальная **Ollama**, автономный файл **GGUF** или облачный **OpenRouter**). После запуска интерфейс автоматически откроется в браузере.
